# ChatHub — شات جماعي وخاص

مشروع واجهة محادثات عربية RTL باستخدام Bootstrap 5 وCSS وJavaScript وSupabase.

## المتطلبات
- حساب Supabase.
- متصفح حديث.
- HTTPS لتسجيل الصوت والإشعارات (GitHub Pages يوفر HTTPS).

## 1) إعداد Supabase
1. أنشئ مشروعاً جديداً من https://supabase.com/.
2. افتح SQL Editor ثم الصق محتوى `supabase/schema.sql` ونفّذه.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. افتح `js/config.js` وضع القيم مكان:
   - `YOUR_SUPABASE_PROJECT_URL`
   - `YOUR_SUPABASE_ANON_KEY`
5. لا تستخدم `service_role` أو أي مفتاح سري داخل ملفات المتصفح.
6. من Authentication > URL Configuration أضف رابط موقعك في Site URL و Redirect URLs.
7. من Database > Replication / Publications فعّل Realtime لجدول `messages`.

## 2) تشغيل محلي
يمكن فتح `index.html` للتجربة الأساسية، لكن الأفضل تشغيله عبر خادم محلي:
- VS Code: إضافة Live Server ثم Open with Live Server.
- أو Python: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## 3) رفع المشروع على GitHub Pages
1. أنشئ مستودع GitHub جديداً (Public أو Private).
2. ارفع ملفات المجلد إلى جذر المستودع.
3. افتح Settings > Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر `main` ثم `/ (root)` واضغط Save.
6. انتظر رابط الموقع الذي يظهر في صفحة Pages.
7. أضف الرابط إلى Supabase Authentication > URL Configuration.

ملاحظة: GitHub Pages استضافة ملفات ثابتة فقط. قاعدة البيانات والمصادقة والتخزين تعمل على Supabase.

## 4) تجربة الموقع
1. افتح رابط الموقع وأنشئ حساباً بالبريد الإلكتروني.
2. لتعطيل تأكيد البريد وجعل الحساب يدخل مباشرة: افتح Supabase Dashboard > Authentication > Sign In / Providers > Email، ثم عطّل خيار Confirm email واحفظ التغييرات. قد يختلف اسم القسم قليلاً حسب إصدار لوحة التحكم.
3. بعد تعطيل التأكيد، أنشئ الحساب وسيتم تسجيل الدخول مباشرة. أنشئ حساباً ثانياً ببريد آخر من نافذة خاصة أو متصفح آخر.
4. تظهر الحسابات المسجلة في قائمة "كل المستخدمين" ويمكن الضغط على أي مستخدم لفتح محادثة خاصة معه.
4. ابدأ محادثة خاصة باستخدام البريد الإلكتروني للحساب الثاني.
5. أنشئ مجموعة وأدخل عناوين بريد الأعضاء المسجلين.
6. جرّب النصوص والمرفقات والرسائل الصوتية.

## ملاحظات مهمة قبل الاستخدام الفعلي
- هذه نسخة بداية قابلة للتشغيل والتطوير وليست منتجاً جاهزاً للإنتاج.
- الإشعارات الحالية إشعارات متصفح أثناء فتح الموقع/وجود جلسة نشطة؛ إشعارات Push حتى عند إغلاق المتصفح تحتاج Web Push وخادماً موثوقاً/Edge Function وتخزين اشتراكات.
- لا يوجد حالياً رفع/حذف أعضاء من واجهة إدارة المجموعة، ولا حالات قراءة/تسليم متقدمة.
- سياسة قراءة ملفات التخزين تعتمد على عضوية المحادثة، والملفات في bucket خاص وروابطها مؤقتة.
- قائمة "كل المستخدمين" تعرض أسماء وبريد الحسابات للمستخدمين المسجلين. هذا يحقق طلب ظهور المستخدمين لبعضهم، لكنه يعني أن البريد الإلكتروني ظاهر لكل مستخدم مسجل؛ إذا أردت خصوصية أعلى، يمكن إخفاء البريد وعرض الاسم والصورة فقط.
- حد الملف الافتراضي 20MB ويمكن تغييره من SQL وسياسات Storage.
- قبل النشر العام، راجع سياسات RLS واختبرها بحسابين مختلفين، وأضف CAPTCHA ومحددات إساءة الاستخدام وسياسة خصوصية وشروط استخدام.
